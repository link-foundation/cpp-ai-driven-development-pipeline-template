# Source: https://learn.microsoft.com/en-us/nuget/guides/native-packages (ms.date 2017-01-09, updated 2025-10-31)
"To be consumable in a C++ project, a package must target the native framework."
"Native NuGet packages targeting native then provide files in \build, \content, and \tools folders; \lib is not used in this case (NuGet cannot directly add references to a C++ project). A package may also include targets and props files in \build that NuGet will automatically import ... Those files must be named the same as the package ID with the .targets and/or .props extensions."
"Be sure to include native in the <tags> section of your .nuspec"
